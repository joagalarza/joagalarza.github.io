# Mi sitio personal

Este paquete contiene los archivos listos para publicar con GitHub Pages.

## Publicarlo
1. Crea un repositorio público llamado `mywebsite` en GitHub.
2. Descomprime este ZIP y sube todos los archivos y carpetas de su interior a la raíz del repositorio. `index.html` debe quedar en la raíz.
3. En el repositorio abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**, selecciona la rama `main` y la carpeta `/(root)`, y pulsa **Save**.
5. Espera a que termine la publicación. La dirección del sitio será `https://joaenciencia.github.io/mywebsite/`.

Si en cambio quieres que la dirección sea `https://joaenciencia.github.io/` sin `/mywebsite/`, el repositorio debe llamarse `Joaenciencia.github.io`.
